<b>Game Description:</b>
-
Join Fern on a narrative quest as he ventures inside a scary cave inhabited by ferocious monsters that seek to stop him! Many things await him inside the cave; is there more going on behind the scenes than he thinks? 

<b>Controls:</b>
-
WASD or Arrow Keys, Space = move/crouch/jump

C or Left Shift = dash

Z or Left Mouse-Click = attack

Mouse Scroll or Keys 1, 2, 3, 4 = swap weapons
